# 📝 Online Job Application Form

This project is a simple **HTML-based Job Application Form** that collects a user's personal details, educational background, and work experience in a well-structured and visually clean format.  
It demonstrates the use of HTML5 form elements, basic validation, and simple CSS styling.

---

## 🌐 Live Demo

👉 **[View the Hosted Form Here](https://ham-2k5.github.io/Job_Application-Form/)**  
---

## 🚀 Features

- ✅ Clean and responsive design  
- 📋 Sectioned layout for personal, education, and work details  
- 🧾 HTML5 validation with `required`, `pattern`, and date inputs  
- 🎨 Simple and accessible CSS for readability  
- 🧠 Proper `<label>` usage for better accessibility  
- 🕓 Submit and Reset buttons for user control
